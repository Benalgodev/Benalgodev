# Bénédiction Mulemba

Chef de projet EDI & facturation électronique. Je fais circuler les factures entre ERP, plateformes agréées et partenaires — et je code les outils qui rendent ces flux fiables.

**Ce sur quoi je travaille**
- Intégration de flux de facturation : UBL, CII, Factur-X, EDIFACT INVOIC, IDoc INVOIC02
- Réforme française 2026-2027 : plateformes agréées, cycle de vie (statuts CDAR), e-reporting
- Norme EN 16931 : modèle sémantique, règles de calcul, validation Schematron
- Pilotage du run : rejets, mappings, recette avec les prestataires

**Projets**

| Projet | Ce que ça fait |
|---|---|
| [einvoice-core](https://github.com/Benalgodev/einvoice-core) | Bibliothèque Python : modèle EN 16931, calculs de totaux et de TVA, lecture/écriture UBL et CII |
| [annuaire-pa-watch](https://github.com/Benalgodev/annuaire-pa-watch) | Veille automatique de la liste officielle des plateformes agréées, avec historique des changements |

**Outils** : Python · SQL · XML/XSLT/Schematron · EDIFACT · SAP IDoc · Java · TypeScript · GitHub Actions · Docker
